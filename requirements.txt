# 系统依赖（非 pip）：
#   ffmpeg —— 浏览器（尤其 Linux 上的 Chromium）没有 AAC 音频编码器，
#   MP4 导出时由本机 ffmpeg 把「无声视频 + WAV 音轨」交织封装成带 AAC 的 MP4。
#   找不到 ffmpeg 时会退化成导出无声视频（编辑器里会有控制台警告）。

# 字幕转录（yuancut_asr/）用到 torch / transformers / numpy：
